# IITM BS PYQ Topics: most repeated topics for 44 courses

Which topics come up most in **IIT Madras BS** past papers? This repo answers that for 44 courses, Foundation to Degree level. 4,623 past questions (Qualifier, Quiz 1, Quiz 2 and End Term) were each tagged with one topic, then counted. Each course file also lists the question types that come back in different papers.

Use it to plan revision: start with the topics at the top of each list.
